# M7.2.3 — explicit UnixStream worker-channel type

Rust 1.99.0 reported a future-incompatible never-type inference warning and
then inferred the bounded IPC channel element as `!`. That caused the worker's
`stream` value to lose its `UnixStream` methods and made `try_send(UnixStream)`
fail with `expected !`.

The bounded channel now explicitly declares its element type:

```rust
mpsc::sync_channel::<std::os::unix::net::UnixStream>(QUEUE_DEPTH)
```

This is intentionally a type-only fix. Worker count, queue depth, timeouts,
capability authentication, and fail-closed overload behavior are unchanged.

A static regression check prevents the untyped channel form from returning.
