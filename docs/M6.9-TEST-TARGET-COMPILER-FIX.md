# M6.9 — Test-target compiler fix and expiry smoke assertions

The next real Rust 1.99.0 pass reached `jend-core` test compilation.

`Result::unwrap_err()` requires the successful value type to implement
`Debug`. `ConversationSeed` deliberately does not implement `Debug` because it
contains secret key material. The failing test now checks
`matches!(result, Err(JendError::Aead))` instead of adding `Debug` to the secret
type.

The same run also exposed five `jend-cli` dead-field warnings for server expiry
timestamps. Those fields are now actively validated by the smoke client:

- registration bootstrap expiry;
- login account-capability expiry;
- device-binding challenge expiry and wire/decoded agreement;
- device capability expiry;
- refreshed capability expiry;
- trusted-device session challenge expiry and agreement;
- trusted-device capability expiry.

This converts warnings into useful protocol sanity checks rather than hiding
them with allow attributes.

This checkpoint remains compiler-driven; it does not yet claim the complete
workspace or PostgreSQL smoke is green.
