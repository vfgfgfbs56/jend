# M6.8 — Vault compiler fixes from the fourth macOS run

The next real Rust 1.99.0 workspace pass reached `jend-vault` and reported
three E0308 errors (four affected arguments).

`SecretStore::load_or_create_32` returns `Zeroizing<[u8; 32]>`. Calling
`.as_mut()` exposes `&mut [u8]`, but the key-import constructors deliberately
require `&mut [u8; 32]`.

Fixed imports:
- AccountRootKey;
- DeviceIdentity;
- SyncDeviceIdentity signing key;
- SyncDeviceIdentity X25519 key.

They now use explicit fixed-array mutable dereference (`&mut *secret`).

This checkpoint also removes two dead gateway paths that produced warnings:
- the never-constructed synchronous `PgGatewayRepository` adapter;
- the superseded `compare_and_swap_device_set_async` function.

The live DeviceSet mutation path remains
`compare_and_swap_device_set_with_jreq`, which atomically consumes the JREQ
nonce and applies the CAS update.

This revision is compiler-driven but does not yet claim the complete workspace
or PostgreSQL smoke test is green.
