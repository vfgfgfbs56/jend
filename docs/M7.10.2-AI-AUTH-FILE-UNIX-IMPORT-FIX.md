# M7.10.2 — Unix OpenOptionsExt import fix

Rust 1.99.0 reached the `jend-aid` binary and correctly rejected
`OpenOptions::mode(0o600)` because the Unix `OpenOptionsExt` trait was not in
scope.

M7.10.2 imports `std::os::unix::fs::OpenOptionsExt` alongside
`PermissionsExt`. The auth capability file continues to use `create_new(true)`
and is created with mode `0600` before being written.

No runtime protocol, capability format, queue behavior, security policy, or
dependency graph changed.
