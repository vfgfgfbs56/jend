# M8.5.5.1 — Xorb decoder negative-test compile fix

The M8.5.5 negative tests used `Result::unwrap_err()`. Rust requires the
success type `T` to implement `Debug` for `unwrap_err()`, but the success type
`DecodedXorbRange` contains decoded model bytes and intentionally does not
implement `Debug`.

M8.5.5.1 changes only the tests: they pattern-match `Result` and compare the
error value without formatting a successful decoded payload. Production xorb
decoding behavior is unchanged, and `DecodedXorbRange` remains non-`Debug`.
