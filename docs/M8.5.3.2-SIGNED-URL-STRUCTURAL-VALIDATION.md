# M8.5.3.2 — Structural signed-Xorb URL validation

The previous validator searched the entire signed URL for `@`. That was too
brittle because authorization query values are opaque; SSRF/userinfo checks
only need to constrain the URL authority.

This patch explicitly separates scheme, authority, path and query. It requires:
- HTTPS only;
- exact HF Xet transfer hostname with no userinfo or explicit port;
- exact `/xorb/default/<hash>` or live `/xorbs/default/<hash>` path;
- exact expected xorb hash in the path;
- a non-empty `X-Xet-Signed-Range` query parameter;
- no fragment;
- a bounded 64 KiB signed URL.

Signed query values are never logged. Specific non-secret parser error variants
identify whether a live failure is length, scheme, host, path or missing signed
range. M8.5.3.2 still does not execute a signed Xorb URL.
