# M8.5.2.1 — Xet metadata smoke cleanup

This patch does not change the Xet parsing/security contract. It makes the
runtime smoke exercise both the read-grant and reconstruction parsers, reads
its relevant result fields, and scopes `dead_code` suppression to the private
smoke-only module import. Project-wide warnings remain enabled.

The smoke script still runs `cargo test` before `cargo run`; the previous
misleading runtime message telling the operator to run cargo test was removed.
