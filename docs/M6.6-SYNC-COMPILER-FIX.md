# M6.6 — Sync compiler fixes from the second macOS run

The second real Rust 1.99.0 compiler pass reached `jend-sync` and reported four
E0308 type errors.

The affected code wrapped X25519 shared secrets in `Zeroizing<[u8; 32]>`, then
called `.as_ref()`. That method exposes a byte slice (`&[u8]`), while the
domain-separated KDF helpers intentionally accept fixed-size `&[u8; 32]`
inputs.

Fixed call sites:

- `jend-sync/src/envelope.rs`: two `derive_envelope_key` calls;
- `jend-sync/src/recovery.rs`: two `derive_approval_key` calls.

They now use explicit array-preserving dereference (`&*shared`).

Static preflight now rejects reintroduction of the four slice-erasing call
sites.

This checkpoint is based on real compiler diagnostics supplied from macOS. It
does not yet claim the full workspace is green; the next run should proceed to
the next compiler/test result.
