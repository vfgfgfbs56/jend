# M5.5 — Build/test baseline

This milestone turns the headless source tree into a reproducible test target.

## Added

- `rust-toolchain.toml` pins the declared MSRV toolchain to Rust 1.85.0.
- `.github/workflows/headless-ci.yml` runs format, workspace check, unit tests,
  a real PostgreSQL service, migrations, gateway startup and the CLI smoke flow.
- `scripts/ci-headless-smoke.sh` performs the end-to-end local/CI test.
- `jend-cli smoke-register ... --password-stdin` enables explicit noninteractive
  development testing without weakening the default interactive behavior.
- The smoke client now asserts three negative security properties:
  1. a device bearer token without JREQ is rejected;
  2. replaying an already accepted JREQ proof is rejected;
  3. replaying an already accepted device-session proof is rejected.

## Definition of PASS

M5.5 is only considered **verified** after all of these complete on the same
revision:

```text
cargo fmt --all -- --check
cargo check --workspace --all-targets
cargo test --workspace
scripts/ci-headless-smoke.sh
```

A source archive containing this harness is **not** itself evidence that the
commands passed.

## Current execution-environment limitation

The ChatGPT build container used to prepare this milestone has no Rust,
PostgreSQL or Docker installed, and outbound package/toolchain downloads are
blocked. Therefore the included CI/harness is ready to run, but this archive is
not yet being labeled "compiled and passing".

The next actionable result from a machine/CI runner with network access is the
compiler/test log itself. Any failures should be fixed before adding new product
features.
