# M8.5.7.1 — multi-xorb assembler smoke expectation fix

The M8.5.7 production assembler was correct, but its executable smoke had an
incorrect suffix expectation. With `offset_into_first_range = 3`, a request of
`total + 3` bytes consumes `total - 3` bytes from the first term and all six
bytes from the second `"second"` term. The smoke incorrectly expected the
result to end in `"sec"`.

M8.5.7.1 changes only the smoke assertion: it now checks the exact output
length, the expected first bytes after the offset, and the complete `"second"`
suffix. The assembler implementation is unchanged.
