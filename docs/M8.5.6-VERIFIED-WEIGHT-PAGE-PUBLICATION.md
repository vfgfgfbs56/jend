# M8.5.6 — Verified WeightPage publication

M8.5.6 closes the trust gap between bytes reconstructed by an external source
adapter and bytes that WeightVM is allowed to consume.

## Trust chain

1. A release key verifies the signed virtual model map.
2. The same release key verifies the signed source map.
3. The source map must cover exactly the WeightPage identities in the virtual
   map for the same model/release.
4. Only then can `ModelReleasePublicKey::verify_source_read_request` mint an
   opaque `VerifiedSourceReadRequest`.
5. `DurableWeightPageStore::put_verified_source_page` checks exact plaintext
   length and SHA-256 against that token before creating a staging file.
6. Staging bytes are synced and re-read/re-hashed before atomic rename.
7. WeightVM re-checks exact length and SHA-256 before RAM residency.

A failed length/hash check does not create a staging object or a final object.
The source worker therefore cannot make arbitrary reconstructed bytes visible to
WeightVM merely by choosing its own expected hash.

`subtle::ConstantTimeEq` is used for 32-byte digest equality in the durable
store and WeightVM. Page digests are public identities rather than secrets, but
using one comparison primitive avoids accidental early-exit comparison drift.

## Scope

This milestone is transport-independent. M8.5.5 already proved real HF/Xet xorb
decode on macOS. M8.5.6 proves the signed Jend integrity/publication boundary
with deterministic local fixtures. It intentionally does **not** pretend the
public GPT-2 live probe already has a Jend release-signed page map; publishing a
live HF-derived page requires a real signed Jend virtual/source map for that
release.

When upgrading from M8.5.5.1, keep the existing `Cargo.lock` and extend its
workspace dependency edge once (the pinned `subtle 2.6.1` package is normally
already present through `jend-auth`):

```bash
bash scripts/prepare-m8.5.6-lock.sh
```

Then run:

```bash
bash scripts/dev-verified-weight-page-smoke.sh
```

Expected gates include signed-map request authorization, digest/length rejection
before staging, durable publication, and WeightVM admission from the verified
store.
