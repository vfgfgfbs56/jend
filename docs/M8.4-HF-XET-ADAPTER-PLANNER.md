# M8.4 — HF/Xet source-adapter planner

M8.3 made WeightVM source-independent. M8.4 adds the first concrete source
adapter protocol for Hugging Face Xet without adding a network client to
`jend-model-store`.

The current Xet path is modeled as: immutable Hub resolve -> `X-Xet-Hash` ->
repo/ref-scoped read token -> exact-range CAS reconstruction -> signed xorb
ranges. Resolve redirects are rejected rather than followed.

The planner validates current US/EU CAS and transfer endpoints, 64-hex file/xorb
identities, range ordering, term coverage and bounded transfer budgets. Secret
Xet tokens and signed URLs use `Zeroizing<String>` and intentionally are not
Debug.

M8.4 does not perform HTTP, DNS, JSON parsing, multipart parsing, xorb chunk
decoding or decompression. M8.5 will place those operations in an isolated
source worker with DNS pinning and streaming verification into the durable
WeightVM page store.
