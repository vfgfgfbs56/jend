# M8.5.3 — Live Xet read token + CAS v2 reconstruction

M8.5.3 connects the already-pinned HTTPS transport to the schema-correct Xet
metadata parser. It is deliberately a **metadata-only** live milestone.

The explicit live smoke:

1. resolves an immutable Hub file without following the 302 and reads
   `X-Xet-Hash`;
2. uses `JEND_HF_TOKEN` only to request a short-lived Xet `read` token scoped to
   the same repository and immutable commit;
3. validates `accessToken`, expiry and the CAS host without logging secrets;
4. calls `GET /v2/reconstructions/{file_id}` with `Range: bytes=0-0`;
5. validates the real `QueryReconstructionResponse` with the M8.5.2.2 parser;
6. stops before any signed xorb URL is executed.

No model payload is downloaded by this milestone. Signed transfer URLs remain
secret-bearing metadata only. Xorb transfer, multipart/byteranges parsing,
xorb deserialization/decompression and WeightPage SHA-256 verification remain
future milestones.

The live smoke intentionally does not inherit `HF_TOKEN`. The operator must
explicitly export `JEND_HF_TOKEN` for this command so credentials do not become
an ambient dependency of Jend.
