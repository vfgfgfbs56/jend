# M8.0.1 — WeightVM smoke Result-alias compiler fix

The M8.0 WeightVM library code compiled far enough for Rust 1.99.0 to reach the
smoke binary, where the binary imported `jend_model_store::Result`.

That alias is `Result<T> = Result<T, ModelStoreError>` and accepts one generic
argument. The smoke `main` incorrectly tried to use it as
`Result<(), Box<dyn Error>>`, which also made string `.into()` failures target
`ModelStoreError`.

M8.0.1 removes the alias from the smoke import:

- `WeightPageSource::read_page` explicitly returns
  `jend_model_store::Result<Vec<u8>>`;
- `main` explicitly returns
  `std::result::Result<(), Box<dyn std::error::Error>>`.

WeightVM runtime/cache behavior is unchanged.
