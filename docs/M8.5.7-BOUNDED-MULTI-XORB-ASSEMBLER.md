# M8.5.7 — Bounded multi-xorb logical assembler (offline foundation)

This milestone adds `reconstruct_slice_from_ranges` to the CLI's transport-independent xorb decoder. It assembles a bounded logical slice across multiple reconstruction terms, xorb hashes, and already-decoded physical ranges, with exact chunk-index binding.

Security gates: nonzero request; caller-supplied maximum output bytes; missing chunk rejection; duplicate/ambiguous chunk coverage rejection; checked length arithmetic; every term's `unpacked_length` verified, including terms after the requested output is filled; exact final logical slice length. No model bytes are formatted using `Debug`.

This is **not** a live multi-range transport or an end-to-end verified WeightPage. The current network worker still fetches a single authorized physical range. The existing signed-map verified-page ingestion is a separate offline gate. Integrating multi-range transport with signed page requests, independent expected hashes, and durable admission is future work.

Run `bash scripts/dev-xet-xorb-decode-smoke.sh` after `bash scripts/first-test-ladder.sh`. The new smoke line is `Jend Xet multi-term multi-xorb logical assembler: PASS`.
