# M4.9 PostgreSQL account repository

- Corrected PostgreSQL UUID decoding (UUID is not a BYTEA).
- Added async `insert_registered_account` with unique-username conflict handling.
- `account_by_username` now filters disabled accounts.
- OPAQUE password file must be produced by validated registration-finish logic;
  this repository **does not** verify an OPAQUE exchange.
- HTTP registration remains `503` until OPAQUE start/finish and admission are
  integrated in one safe flow. Never expose `insert_registered_account` directly.
- Production still requires key management, session replay controls,
  database tests, load tests, and security review.
