# M7.2.2 — SensitiveBytes type fix

The first Rust 1.99.0 compilation of M7.2.1 reached the new authenticated Vault
IPC execution path and found a type mismatch.

`decode_append()` already returns `SensitiveBytes`, while `Vault::append_message`
takes ownership of `SensitiveBytes`. M7.2.1 incorrectly converted that value
back to `&[u8]`.

M7.2.2 passes the sensitive buffer by value directly. This preserves the
intended ownership/zeroization boundary and avoids creating an unnecessary
borrowed plaintext view.

A static regression check now prevents the `.as_bytes()` downgrade from being
reintroduced at this call site.
