# M8.5.0 — Source Worker transport response gate

Adds a bounded HTTP response state machine and public-IP DNS validation
contract. Requires HTTP 206 for exact ranges, rejects 200 full-file fallbacks,
enforces declared response byte limits, rejects redirects, and requires complete
range length before releasing a byte buffer.

**Not implemented:** OS-isolated process, actual HTTP transport, DNS pinning
at socket connection time, Xet JSON/multipart parser, xorb decompression,
page hashing and durable WeightVM ingestion. The worker gate alone is not a
complete secure downloader; the transport must enforce TLS SNI, certificate
validation and pinned IPs and must never feed raw bytes to inference.
