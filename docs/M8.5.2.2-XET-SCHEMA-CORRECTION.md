# M8.5.2.2 — Xet v2 reconstruction schema correction

The earlier M8.5.2 test fixture was not faithful to the published v2 response
shape. It represented `terms` chunk bounds as flat `start/end` fields and
represented `xorbs` as an array. The published Xet v2 protocol instead uses:

- `terms[].range = { start, end }`;
- `xorbs` as a map keyed by 64-lowercase-hex xorb hash;
- each map value as an array of fetch entries;
- `ranges[].chunks = { start, end }` (end-exclusive);
- `ranges[].bytes = { start, end }` (end-inclusive).

M8.5.2.2 corrects the parser and smoke fixture to exactly this structural
shape and adds a regression test that rejects the old incorrect fixture.

This milestone remains offline. It does not execute signed URLs and does not
claim live CAS compatibility until the next milestone validates an actual
read-token and `/v2/reconstructions/{file_id}` response.
