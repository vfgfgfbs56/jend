# M8.5.2 — Strict Xet metadata parsing (offline)

Bounded JSON parser for short-lived Xet read tokens and typed reconstruction
metadata with allowlisted CAS/transfer hosts, term coverage and range limits.

Not yet connected to live transport: actual upstream response schema must be
validated against live fixtures before enabling downloads. Does not implement
multipart/byteranges, xorb decoding, process sandbox or page verification.
No arbitrary signed URL is executed by this milestone.
