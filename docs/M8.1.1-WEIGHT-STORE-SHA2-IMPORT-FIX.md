# M8.1.1 — Durable Weight Store SHA-256 trait import fix

Rust 1.99.0 reported that `sha2::Sha256::new()` was unavailable because the
`sha2::Digest` trait was imported only later inside the read loop.

M8.1.1 moves `use sha2::Digest;` into module scope so `new`, `update`, and
`finalize` are all resolved correctly.

The race-tolerant atomic publish arm also renames its intentionally unused
`rename_error` binding to `_rename_error`, removing the compiler warning.

No durable-store layout, hashing semantics, permissions, crash recovery,
WeightVM behavior, or dependency graph changed.
