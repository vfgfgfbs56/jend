# M6.7 — Axum compiler fix from the third macOS run

The third real Rust 1.99.0 compiler pass reached `jend-gateway` and reported
that `/v1/registration/admission` was being wired with a `RegistrationAdmission`
value rather than an Axum handler.

Root cause: a local binding named `registration_admission` in `main()` shadowed
the async handler function of the same name. The local service value is now
named `registration_admission_service`.

The same compiler run also reported the tower-http 0.6 deprecation of
`TimeoutLayer::new`. The gateway now uses
`TimeoutLayer::with_status_code(StatusCode::REQUEST_TIMEOUT, ...)`, preserving
the previous 408 behavior explicitly.

Static preflight now rejects any future collision between route-handler names
and `let` bindings in `main()`, and rejects the deprecated timeout constructor.

This remains a compiler-driven checkpoint, not yet a claim of a fully green
workspace or PostgreSQL smoke test.
