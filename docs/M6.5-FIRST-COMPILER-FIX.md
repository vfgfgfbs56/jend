# M6.5 — First real compiler fix

The first external macOS `cargo test` reached Jend source code and reported two
E0308 errors in `jend-core/src/ratchet.rs`.

`Zeroizing<[u8; 32]>::as_ref()` returns `&[u8]`, while `derive_step` requires
`&[u8; 32]`. Both ratchet call sites now use an explicit deref coercion:

`derive_step(&*self.chain_key, seq)`

This milestone also makes `scripts/verify-manifest.py` ignore:
- macOS `.DS_Store` files anywhere in the tree;
- root-level `.log` files produced by test commands.

`Cargo.lock`, `target/`, `.git/`, and dev secret directories remain generated
artifacts and are excluded from source-manifest inventory as before.

This is based on a real Rust 1.99.0 compiler report from macOS. It does not yet
claim the complete workspace compiles; the next external run should continue
from the next compiler/test failure, if any.
